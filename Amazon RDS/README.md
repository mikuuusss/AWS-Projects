Project Overview 

Designed and deployed a fully managed relational database using Amazon RDS (Aurora/MySQL) on AWS Cloud. Configured secure database connectivity from an Amazon EC2 Linux instance, created relational database tables, populated sample datasets, and executed SQL queries including joins to demonstrate database management and querying skills.  

Technologies Used:
  -Amazon Web Services (AWS)  
  -Amazon RDS  
  -Amazon Aurora / MySQL  
  -Amazon EC2 (Amazon Linux)  
  -MariaDB Client  
  -Linux  
  -SQL  
  -AWS VPC  
  -Security Groups  
  -SSH
