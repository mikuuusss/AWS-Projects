Project Objective:
Build a production-style, multi-AZ AWS network from scratch and 
deploy a publicly accessible Apache web server on EC2 — demonstrating secure VPC design with public/private subnet isolation, proper routing, and instance-level firewalling.

AWS Services used:
  Amazon VPC	
  Subnets	
  Internet Gateway (IGW)
  NAT Gateway	
  Route Tables	
  Security Groups	
  Amazon EC2
