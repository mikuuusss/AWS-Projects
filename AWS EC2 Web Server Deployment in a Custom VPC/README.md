Project Overview 
This project demonstrates how to deploy a secure web application on an Amazon EC2 instance inside a custom Virtual Private Cloud (VPC). The infrastructure was built from scratch using AWS networking services, and an Apache web server was configured using Linux commands and EC2 user data. 
The project highlights core AWS infrastructure skills including networking, security, compute, and Linux administration. 

AWS services used:
  Amazon EC2 
  Amazon VPC 
  Public Subnet 
  Internet Gateway 
  Route Tables 
  Security Groups 
  EC2 Instance Connect / SSH 
  Amazon Linux 
  EBS (General Purpose SSD - gp2)
